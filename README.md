# cfgaudit examples

A small repository that shows where [cfgaudit](https://github.com/cfgaudit/cfgaudit) findings appear in GitLab. The pipeline includes the `cfgaudit-code-quality` component, so a merge request that adds risky AI-agent configuration lists the findings in its Code Quality widget.

The open merge request adds such a configuration on purpose. Do not copy it into a real project.
